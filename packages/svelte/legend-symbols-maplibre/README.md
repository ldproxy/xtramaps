# @xtramaps/legend-symbols-maplibre-svelte

Svelte components for generating legend symbols from MapLibre styles.

## Install

```sh
npm install @xtramaps/legend-symbols-maplibre-svelte
```

Requires `svelte` as a peer dependency.

## Usage

```ts
import { greet } from "@xtramaps/legend-symbols-maplibre-svelte";
```
