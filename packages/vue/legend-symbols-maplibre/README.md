# @xtramaps/legend-symbols-maplibre-vue

Vue components for generating legend symbols from MapLibre styles.

## Install

```sh
npm install @xtramaps/legend-symbols-maplibre-vue
```

Requires `vue` as a peer dependency.

## Usage

```ts
import { greet } from "@xtramaps/legend-symbols-maplibre-vue";
```
