# @xtramaps/legend-symbols-maplibre-react

React components for generating legend symbols from MapLibre styles.

## Install

```sh
npm install @xtramaps/legend-symbols-maplibre-react
```

Requires `react` and `react-dom` as peer dependencies.

## Usage

```tsx
import { greet } from "@xtramaps/legend-symbols-maplibre-react";
```
